# Stack Overflow Tag Prediction Project

## 📌 Project Description
This project predicts relevant tags for Stack Overflow questions using Machine Learning.

The model is trained on Stack Overflow question data including:
- Title
- Body
- Tags

It uses NLP techniques such as:
- TF-IDF Vectorization
- Multi-label classification
- Logistic Regression / OneVsRest Classifier

## 🚀 Objective
To automatically suggest tags for a given Stack Overflow question.

## 🛠️ Tech Stack
- Python
- Scikit-learn
- Pandas
- Numpy
- Streamlit (for deployment)

## 📊 Dataset
Stack Overflow public dataset.
